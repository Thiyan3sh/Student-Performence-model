# 🎓 Student Performance Prediction using Machine Learning

This project uses multiple machine learning models to predict student academic performance (High, Medium, Low) based on various factors such as attendance, participation, and class behavior. It also includes data visualization and a manual prediction feature.

# 🧠 ML MODELS USED
The following classifiers are used and compared:

| Classifier           | Description                         |
